## Featured Projects

### Trip Planner

A map-based travel planning web application that supports itinerary creation with location-based features and LLM-assisted planning.

**Technologies:** Next.js, React, Node.js, Tailwind CSS, Google Maps Platform, LLM APIs

**Main work areas:**

- Interactive travel planning interface
- Location and map-based user flows
- LLM-based itinerary generation features
- Full-stack application structure

---

### Indoor Air Quality Anomaly Detection

An IoT and big data system designed to monitor indoor air quality and detect abnormal environmental conditions.

**Technologies:** Raspberry Pi, sensors, Kafka, Spark Streaming, MongoDB, Python, machine learning

**Main work areas:**

- Real-time sensor data collection
- Streaming data pipeline design
- Data processing and storage
- Rule-based and ML-based anomaly detection
- Dashboard-oriented system architecture

---

### Simpsons Character Recognition / X-Ray Style System

A computer vision project focused on detecting and recognizing characters from video frames.

**Technologies:** YOLO, CNN, EfficientNet, ResNet50V2, ViT, Python, deep learning

**Main work areas:**

- Video frame analysis
- Character detection with YOLO
- Classification with custom CNN and transfer learning models
- Model comparison based on accuracy and model complexity
- Character information overlay pipeline

---

### AI Learning Assistant

An LLM-based learning assistant that provides topic explanations and generates quizzes for interactive learning.

**Technologies:** LangChain, Streamlit, Python, LLM APIs

**Main work areas:**

- Topic explanation generation
- Multiple-choice quiz generation
- Structured learning flow
- Educational AI assistant design
